# 🏦 Loan Default Risk Analysis — 2019

## 📌 Project Overview
Analysis of 148,670 loan records worth $49B
to identify default risk patterns and factors.

## 🛠️ Tools Used
- Python (Pandas) — Data Cleaning
- MySQL          — SQL Analysis  
- Power BI       — Dashboard

## 📊 Key Findings
- Low income borrowers default at 39.8%
- Credit score shows minimal predictive power
- Low Income + FHA loans = 49.9% default rate
- Extreme LTV + Home Improvement = 100% default
- Income is #1 predictor — not credit score!
